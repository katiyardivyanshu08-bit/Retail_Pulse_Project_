🛍️ RetailPulse

Customer Segmentation & Sales Forecasting System

RetailPulse is a machine learning project that helps businesses understand customer behavior, identify customer segments, and predict annual customer spending.

✨ Features

- 📊 Customer Segmentation — Groups customers into Budget, Regular, and Premium segments using K-Means clustering.
- 📈 Spending Prediction — Predicts annual purchase amount using Linear Regression.
- 🧹 Data Analysis — Cleans customer data and explores purchasing patterns.
- 💡 Business Insights — Supports better customer analysis and marketing decisions.

🤖 Machine Learning Models

Model| Purpose
K-Means Clustering| Groups similar customers
Linear Regression| Predicts annual purchase amount

📂 Dataset

Contains customer information such as age, region, annual income, purchase frequency, annual purchase amount, customer tenure, and other purchasing details.

🛠️ Tech Stack

"Python" · "Pandas" · "NumPy" · "Scikit-learn" · "Matplotlib" · "Seaborn" · "FastAPI" · "React" · "MySQL"

🎯 Project Goal

To turn customer data into meaningful insights that help businesses understand their customers and make data-driven decisions.
